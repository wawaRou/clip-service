# 01: 通过 TOML 启动服务并接入 Frigate

**What to build:** 用户在原生 uv 环境中通过精简 TOML 启动 CLIP 服务，显式选择 Frigate 转发流，并通过 HTTP 查询各摄像头的连接和缓存状态。保持个人项目的简单实现，沿用已确定的平台组合和 ADR 0001。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 提供只含必要配置的启动示例；支持全局默认值和每路覆盖，凭据与少量部署值可通过环境变量提供，优先级有明确说明。
- [ ] 显式配置单个 Frigate 实例、摄像头标识与 go2rtc 流名映射；不假定摄像头标识等于流名，不硬编码个人模型路径或示例摄像头。
- [ ] 启动时校验配置并给出可定位的错误；空摄像头配置不会回退为示例摄像头，未知或非法配置不会被静默忽略。
- [ ] 持续读取所选转发流并维护有界的短时缓存；HTTP 健康信息可区分各路连接状态、缓存状态及最新帧的新鲜程度。
- [ ] 单路断流不阻止其他流读取；打开和读取有超时、失败可重连、关闭服务有界退出，日志不暴露凭据。
- [ ] 保留已确定的 Python、torch 和平台安装源组合；运行所需依赖由 uv 管理，不使用容器或全局安装。
- [ ] 自动化验证覆盖精简配置启动、覆盖与校验、空列表、断流重连及关闭；提供真实 Frigate 启动和健康查询的简短操作说明。
