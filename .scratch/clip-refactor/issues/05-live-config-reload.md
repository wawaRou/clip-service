# 05: 运行中重载配置并增删改摄像头

**What to build:** 按 ADR 0001，用户修改 TOML 后执行显式重载，即可在服务运行中增删改摄像头及其检测配置；未变化的摄像头继续工作，错误配置不会替换有效配置。

**Blocked by:** 03 — 多路摄像头共享模型并按目标 FPS 检测；04 — 断线、回执超时和服务重启后恢复工作。

**Status:** ready-for-agent

- [ ] 提供显式重载入口和使用说明；TOML 保持唯一持久配置来源，不引入自动监听或另一套可写配置存储。
- [ ] 先完整校验再应用差异，校验失败保留旧配置并报告具体原因；未变化的摄像头不重启、不丢失会话。
- [ ] 新增摄像头后开始拉流和缓存，并可由 Agent Server 开启检测会话；共享模型不会为新摄像头重复加载。
- [ ] 修改全局默认值影响继承该值的摄像头，显式覆盖继续生效；目标 FPS 变化会更新调度。
- [ ] 普通检测参数变化保留会话和已有候选，重置尚未确认的变化计时；已有候选的图片与内容不被新配置改写。
- [ ] 视频流切换、禁用或删除摄像头结束该路会话并通知 Agent Server，安全处置旧候选及迟到操作，其他路继续运行。
- [ ] 不支持热改的服务级设置明确提示需要重启；运行中应用遇到拉流失败时如实报告该路状态，不把部分成功描述成全部成功。
- [ ] 自动化端到端验证覆盖新增、删除、流切换、参数及全局默认值变更、非法配置拒绝，以及重载与回执并发的兜底行为。
