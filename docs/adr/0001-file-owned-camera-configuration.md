# 用 TOML 统一管理摄像头配置，通过显式重载生效

这是个人使用的小项目，需要动态增删改摄像头，同时保持配置管理简单。采用独立 TOML 作为唯一持久配置来源，提供全局默认值和每路覆盖；修改后显式重载，先校验再按差异应用，校验失败继续使用旧配置。选择这一方式，是为了避免文件与管理 API 同时维护配置带来的同步问题，也不需要自动监听文件。

普通检测参数调整保留会话与已有候选，重置尚未确认的变化计时；切换视频流、禁用或删除摄像头则结束该路会话并通知 Agent Server，其他摄像头继续运行。所有流均由单个 Frigate 实例提供，显式配置摄像头与 go2rtc 转发流的映射。
